# Khushi 3D immersive portfolio

Interior design portfolio as a 3D walk-through: a studio desk, a laptop that lists the projects,
and The Arch House villa to walk through. Live at https://kishu.studio/Khushi.office/

Stack: React 18, Vite, three.js, React Three Fiber, drei, Lenis, GSAP.

    npm install
    npm run dev      # http://127.0.0.1:5190
    npm run build    # dist/, deployed to the gh-pages branch

URL options: `?gallery` (light image version), `?full` (skip the GPU check), `?stats`.

Textures, HDRIs and desk models: Poly Haven, CC0. Renders: Khushi's own work, all rights reserved.
